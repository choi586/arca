# ☁️ 구름섬 아르카

여러 명이 함께 노는 3D 브라우저 RPG예요. 지금은 **11단계(새 무기와 펫 능력)** 까지 만들었어요.

배포 주소: https://arca-hy58.onrender.com

## 지금 되는 것
- 이름, 옷 색깔, 모자를 고르고 섬에 들어가기
- 하늘에 떠 있는 섬 '포근언덕': 광장 분수, 집 5채, 나무, 바위, 꽃, 멀리 떠 있는 섬과 구름
- 여러 명이 동시에 접속해서 서로의 캐릭터 보기 (한 채널 최대 40명, 넘치면 채널 2가 열림)
- 채팅(말풍선 + 채팅창), 감정표현(인사·춤·앉기)
- 걷기, 달리기, 점프, 섬 밖으로 떨어지면 광장에서 다시 시작
- 작은 지도, 휴대폰 조작(조이스틱, 버튼)
- 연결이 끊기면 자동으로 다시 연결

## 2단계에서 생긴 것
- 몬스터 3종: 말랑 슬라임(Lv1, 광장 주변), 버섯돌이(Lv4, 숲), 이끼 돌거북(Lv8, 큰 언덕)
- 몬스터는 공격하기 전에 바닥에 빨간 원을 보여 줘요 → 원 밖으로 피하면 안 다쳐요
- 기술: 기본 공격(클릭/F), 회전베기(Q, Lv2), 돌진 찌르기(E, Lv3), 치유의 바람(R, Lv4 — 근처 친구도 회복)
- 체력, 경험치, 레벨 업 (최대 Lv30). 같이 때린 사람 모두 경험치를 다 받아요
- 쓰러지면 5초 뒤 광장에서 다시 일어나요. 싸우지 않으면 체력이 조금씩 차요
- 레벨은 브라우저에 저장돼요 (무료 서버가 잠들어도 이어서 할 수 있게)

## 3단계에서 생긴 것
- 몬스터를 잡으면 골드와 재료(슬라임 젤리, 버섯 포자, 이끼 껍질), 가끔 물약이 나와요. 같이 때린 사람 모두 따로 받아요
- 가방(I): 물건 20칸, 무기 바꿔 들기, 물약 마시기(H)
- 광장의 상인 모모(B): 물약과 무기를 사고, 재료를 팔아요
- 무기 5종: 바람검, 참나무 활, 별빛 지팡이, 바위 망치와 방패, 반딧불 등불 — 무기마다 기술 4개가 달라요
- 가방과 골드도 브라우저에 저장돼요

## 4단계에서 생긴 것
- 사람들 창(P): 같은 채널 사람에게 파티 초대, 거래 신청
- 파티(최대 4명): 30걸음 안에 있으면 때리지 않아도 경험치·골드·전리품을 같이 받아요
- 1:1 거래: 골드와 물건을 올리고 둘 다 확인하면 바뀌어요 (무기는 거래 안 됨)
- 월드 보스 폭풍 골렘: 섬 서북쪽에 10분마다 나타나요. 공격 3가지, 기여도에 따라 보상
- 설명서·공략집: `/guide.html`

## 5단계에서 생긴 것
- 글라이더: 공중에서 Space(또는 G)를 한 번 더 누르면 펴져요. 바람 기둥에서 펴면 높이 올라가요
- 버섯숲 섬: 동쪽 바람 기둥을 타고 날아가는 새 섬. 독버섯 두꺼비(Lv10), 숲의 정령(Lv13)
- 낮과 밤: 게임 속 하루는 24분. 밤에는 몬스터 공격 1.25배, 경험치·골드 1.5배
- 꾸미기(K): 모닥불·천막·의자·등불·깃발·화분·팻말을 골드로 사서 놓아요 (8개까지, 접속해 있는 동안 보임)

## 6단계에서 생긴 것
- 촌장 루루의 의뢰 7가지(T): 한 번에 3개까지 맡고, 몇 번이고 다시 할 수 있어요
- 바람의 돌: 의뢰 보상으로 얻어 광장 분수에 바쳐요(V). 서버 전체가 10개를 모으면 두 섬 사이에 걸어서 건너는 바람의 다리가 놓여요 (서버가 잠들면 다시 0)
- 무기 강화: 상인 모모의 '강화' 탭에서 재료와 골드로 +5까지. 한 단계마다 피해 8%
- 10분 동안 움직임이 없으면 섬에서 내보내고, 같은 브라우저로 또 들어오면 먼저 있던 창을 내보내요
- 쓰러진 사람은 9초 뒤 서버가 알아서 일으켜요

## 7단계에서 생긴 것
- 1:1 결투: 사람들 창(P)에서 신청, 수락해야 시작. 피해는 절반, 져도 쓰러지지 않아요
- 칭호 10가지: 사냥·보스·결투·의뢰·강화 기록으로 얻어 이름표 위에 달아요
- 기록·순위 창(L): 내 기록과 지금 접속한 사람들의 레벨·결투 승·사냥 순위

## 8단계에서 생긴 것
- 구름 낚시(X): 섬 가장자리에서 찌를 던지고, 흔들릴 때 맞춰 당겨요. 밤에는 다른 물고기가 낚여요
- 모닥불 요리(C): 잡은 물고기를 구워 먹으면 체력 40% 회복 + 2분 동안 공격력 15%
- 펫 4종: 상인에게 사거나(3종) 낚시로 아주 드물게 만나요(아기 하늘고래). 꾸밈용

## 9단계에서 생긴 것
- 세 번째 섬 ❄️ 서리봉우리: 포근언덕 북쪽 끝의 바람 기둥으로 날아가요. 바닥이 미끄럽고 눈이 내려요
- 몬스터 3종(눈덩이 도깨비 Lv16, 서리 늑대 Lv19, 꼭대기의 서리 거인 Lv24)과 의뢰 3가지
- 광장 안전 구역: 광장 안으로는 몬스터가 못 들어오고 공격받지 않아요

## 10단계에서 생긴 것
- 도전 강화: +6~+10은 성공 확률이 있어요(70%~30%). 실패하면 골드와 재료만 사라지고 단계는 그대로
- 모모의 뽑기 상자: 나무 상자 100G, 황금 상자 500G. 확률은 게임 안에 공개, 황금 상자는 10번 안에 영웅 이상 확정
- 뽑기 전용 장식 5종(목도리·풍선·별·천사 고리·날개)과 펫 2종(황금 슬라임·꼬마 유령)

## 11단계에서 생긴 것
- 새 무기 3종: 그림자 쌍단검(빠름·치명타), 천둥 창(긴 거리·느리게 하기), 달빛 낫(넓게 베기·체력 흡수)
- 펫 능력: 펫마다 작은 능력 하나(골드·경험치·피해 감소·낚시·치명타). 데리고 있는 한 마리만 적용
- 아기 하늘고래는 낚시 성공 100번째에 반드시 나와요

## 조작
WASD 이동 · 마우스 끌기 시점 · 휠 줌 · 클릭/F 공격 · Q·E·R 기술 · H 물약 · I 가방 · B 상점 · P 사람들 · K 꾸미기 · 공중에서 Space 글라이더 · Shift 달리기 · Space 점프 · 1 인사 · 2 춤 · 3 앉기 · Enter 채팅

## 내 컴퓨터에서 실행
```bash
npm install
npm start
```
그다음 브라우저에서 http://localhost:3000 을 열어요. 여러 탭을 열면 여러 명처럼 테스트할 수 있어요.

## 파일
- `server.js` — 파일 서버 + 위치·채팅·몬스터·전투를 맡는 WebSocket 서버
- `public/shared.js` — 서버와 화면이 함께 쓰는 규칙 (섬 모양, 나무 위치, 몬스터, 무기와 기술, 아이템, 레벨)
- `public/game.js` — 3D 섬, 캐릭터, 몬스터, 조작, 화면
- `public/style.css`, `public/index.html` — 화면 꾸미기
- `render.yaml` — Render 무료 배포 설정
